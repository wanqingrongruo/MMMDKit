# MMMDKit v2 Roadmap

## Phase 1：SwiftUI-only 基线

- SwiftUI-only SPM products。
- `MMMDSwiftUI` 渲染入口。
- `MMMDParserSwiftMarkdown` SPM 默认 parser。
- CocoaPods fallback parser。
- v1 UIKit/AppKit podspec 移除。
- README / Usage / Migration 双语文档。

## Phase 2：流式体验

- delta / snapshot 输入。
- incomplete Markdown speculative rewrite。
- streaming metrics。
- 性能监控 demo。
- 列表 demo。

## Phase 3：渲染质量

- 更完整的 SwiftUI block 组件。
- 表格列宽和大表格性能优化。
- 代码高亮缓存。
- 图片预览体验增强。
- 链接、复制、下载、展开默认行为完善。

## Phase 4：生产化

- SwiftUI snapshot tests。
- 更完整的 UI 自动化和截图验证。
- 文档全量双语同步。
- 大文档和大量消息性能基准。
